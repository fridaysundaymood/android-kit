# android-kit

android-kit combines tools for Android devices, UI journeys, localization, local backend testing, and release planning. Use its CLI from a terminal or CI, or connect the stdio MCP server to an MCP client.

- [Getting started](./getting-started.md): prerequisites and first commands on Windows, macOS, and Linux.
- [Lifecycle](./lifecycle.md): where each tool fits and how to interpret results.
- [Fixture walkthrough](./fixture.md): try the tools against synthetic data.
- [Configuration](./android-kit-yaml.md) and [result schema](./kit-schema.md): shared contracts.
